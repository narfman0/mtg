# MTG workspace

- My decks live on Moxfield (source of truth); `decks/` holds cached snapshots, one file per deck (e.g. `decks/satoru.txt`), in plain decklist format: `<count> <Card Name>` per line — mainboard, blank line, commander(s), then an optional `# Considering` section (the Moxfield maybeboard; candidates, not part of the deck).
- When I ask about "my deck" or a deck by name, refresh the cache with `python3 sync_decks.py` (deck name → Moxfield ID mapping is in that script), then read the matching file in `decks/` — don't ask me to paste the list. The script auto-commits and pushes deck changes, building a deck history in git. If Moxfield is unreachable, use the cached file and tell me it may be stale.
- When I say I've changed a deck, re-sync to pull the change from Moxfield. Don't hand-edit deck files (sync overwrites them); if my change isn't on Moxfield yet, remind me to make it there first.
- Proxy printing goes through `python3 print_proxies.py <file.pdf>` (Epson ET-8500) — it forces true 100% scaling and picks the media type that selects the right black (matte pigment vs photo dye). `-p` names the stock loaded in the rear tray and is mandatory — `-p vinyl` for matte vinyl sticker sheets. `--test` prints one page on plain paper to check layout before spending stock.
- Card lookups and rules questions go through the mtg skill (offline oracle database + Comprehensive Rules) — never from memory.
