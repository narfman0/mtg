# Deck descriptions

One markdown file per deck in `decks/`, written for the Moxfield deck description box
(Gameplan, Turn 1, Mulligan, Wincons, Watch out for, Notable). Generated 2026-09-28 from
the deck snapshots of that date; regenerate or hand-edit when a deck changes materially.
Moxfield is the source of truth for the deck list, this folder is the source for the text.
